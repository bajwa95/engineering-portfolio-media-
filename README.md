# Engineering Portfolio Media

Private media library for my engineering portfolio.

This repository stores original photos, videos, screenshots, and other project media before anything is selected for the public portfolio.

The public portfolio is maintained separately in:

`bajwa95/engineering-portfolio`

## Purpose

This repository acts as the private source library for portfolio media.

The workflow is:

1. Upload original project photos and videos here.
2. Keep the original filenames whenever possible.
3. Review the media project by project.
4. Select only the strongest and safest files for public use.
5. Copy the selected media into the public `engineering-portfolio` repository.
6. Rename the public copies according to the portfolio asset structure.

The original media remains private in this repository.

## File Naming

Original files do not need to be renamed before uploading.

For example:

```text
komo/
├── 20250704_074541.jpg
├── 20260525_084419.jpg
├── 20260507_102418.jpg
├── 20260525_084142.mp4
└── WhatsApp Image 2026-10-06 at 10.48.08 AM.jpeg
```

The best files will be selected later and renamed only when copied into the public portfolio.

---

## Public Portfolio Naming

Selected media copied to the public portfolio should use simple descriptive filenames.

Example:

```text
engineering-portfolio/
└── assets/
    └── komo/
        ├── overview.jpg
        ├── alarm.jpg
        ├── damaged-cable.jpg
        ├── tool-carousel.jpg
        └── conveyor.jpg
```

This keeps the website HTML clean while preserving the untouched originals here.

## Media Selection Criteria

When reviewing project media, preference should be given to files that clearly show:

- the complete system or machine
- the engineering problem
- troubleshooting or diagnostic work
- hardware or control-system integration
- the identified root cause
- corrective work
- calibration or alignment
- successful testing
- final operating result
- a useful user interface or software screen

A small number of strong images is preferred over a large collection of repetitive images.

---

## Privacy & Confidentiality

This repository is intentionally private.

Before copying any media into the public portfolio, review it for:

- customer information
- employee information or identifiable people
- company-sensitive documents
- production quantities
- work orders
- drawings
- CNC programs or G-code
- filenames or internal file paths
- passwords or credentials
- network addresses
- IP addresses
- serial numbers where unnecessary
- proprietary service procedures
- internal maintenance parameters
- confidential screens
- company information not needed to tell the engineering story

Images can be cropped or redacted before being published.

Only media intentionally selected for public use should be copied into the public portfolio repository.

---

## Videos

Original videos should remain in this private repository.

For public portfolio use, each video can later be evaluated as one of:

- full video
- shortened clip
- muted clip
- compressed web video
- GIF
- selected still frame

In many cases, a strong still image may communicate the engineering result more clearly than publishing the complete recording.

---

## Image Processing for Public Use

When an image is selected for the public portfolio, the public version may be:

- cropped
- resized
- compressed
- converted to JPEG or WebP
- stripped of EXIF/GPS metadata
- redacted where necessary

The original file should remain unchanged in this repository.

## Portfolio Review Workflow

```text
Private Originals
      ↓
Media Review
      ↓
Select Strongest Evidence
      ↓
Privacy / Confidentiality Check
      ↓
Crop / Redact / Resize if Required
      ↓
Copy Selected Media
      ↓
Public Engineering Portfolio
```

The goal is not to publish every piece of work.

The goal is to build a curated engineering portfolio that clearly demonstrates:

**industrial automation · controls · manufacturing systems · electronics · mechanical troubleshooting · systems integration · software · engineering problem solving**
